# Pixel planet assets

These three transparent decorative assets were generated with OpenAI's built-in image generator, using the user's uploaded astronomical images as subject references and the uploaded pixel-planet poster as a style reference. They were cropped with a safe transparent margin and exported as transparent WebP at a maximum dimension of 640 px, quality 86.

## Earth

- File: `assets/planet-earth-pixel.webp`
- Prompt:

> Create one isolated decorative pixel-art Earth asset for a dark desktop portfolio webpage. Asset type: stylized-concept / transparent UI decoration. Use the first reference image only for Earth's recognizable geography, cloud flow, and blue-green-white palette. Use the second reference image only for the chunky hand-crafted pixel-art visual language. Composition: a single complete round planet, centered, fully visible with generous transparent margin. Show Africa and Europe as simplified readable pixel clusters. Deep navy and teal oceans, muted moss and sand land, soft off-white cloud bands. Use 5–8 deliberate color bands, crisp square pixel steps around the silhouette, subtle lower-right shadow, and a very thin cool-white rim light suitable for a black background. Style: charming retro computer-game sprite, editorial and slightly dreamy, graphic rather than photorealistic. Keep the overall sphere clean and legible at 80–140 CSS pixels. Do not include stars, orbit lines, glow haze, a black rectangle, typography, symbols, watermark, border, or extra objects. Transparent background.
